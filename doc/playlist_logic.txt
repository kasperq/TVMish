PlaylistManager logic

-по умолчанию список наименований плейлистов свернут 
-при выборе плейлиста ячейка расширяется вниз
	-открывается сабтулбар и грид с файлами в плейлисте
	-по умолчанию выбирается файл/категория "Все" даже для пустых плейлистов
	
	
	
-при добавлении файла в плейлист
	-проверяется поддерживаемый формат
	-файл по ссылке копируется в папку с программой "./temp
	-в таблицу файлов заносится локальный путь с именем файла
	-в CHANELS добавляются все каналы из локального файла

-при удалении файла из плейлиста 
	-выбираем количество каналов (DEL_NUM) в нем, если оно >0
		-проходим по файлам после текущего (CUR_ID_FILE)
		-смещаем нумерацию каналов на DEL_NUM
		-переходим к текущему файлу (CUR_ID_FILE) 
		-удаляем каналы в нем
		-удаляем файл
		-выбираем текущий файлы
все каналы после него смещаются наверх
